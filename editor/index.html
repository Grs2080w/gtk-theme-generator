own-theme Studio

A dark theme editor for Zorin OS and GNOME. Pick the base colors and watch the whole theme recalculate. The result is a palette.conf that generate-theme.py turns into a real GTK3, GTK4/libadwaita and GNOME Shell theme.

What each variable changes

Every color of the original theme belongs to a family. When you change a family's base color, all of its colors move together: same hue shift, proportional saturation and remapped lightness. That is why a single choice recalculates dozens of shades.

Button icons: where to get them and how to make them

Close, maximize and minimize can use any SVG or PNG of yours. The theme copies the file into itself and draws it in place of the button, in GTK3 and GTK4 apps (Files, Settings, Text Editor, Terminal…).

The format that works

  • A square SVG, ideally viewBox="0 0 16 16". It is stretched to the size chosen in the control (16 to 26 px). PNG works too: use 64×64 or larger, with a transparent background.
  • The file is the whole button: draw the circle (or any shape you like) and the symbol together, and leave 1 px of margin at the edges.
  • Colors are fixed in the file. They don't follow the accent or change when the window loses focus; in that case the theme just dims the button.
  • No text, fonts or embedded images. In Inkscape: select everything, use Path → Object to Path and Path → Stroke to Path, and save as Optimized SVG.
  • No spaces in the name: icons/close.svg. palette.conf only reads the first word after =.
  • Optional: a restore icon, shown instead of maximize when the window is maximized. Without it, the maximize icon is used.

Ready-made templates: icons/example-*.svg (colored diamonds). Open one in Inkscape and use it as a starting point.

Where to get them

  • Icon Library and Icon Preview (GNOME apps on Flathub): every GNOME symbol to copy as SVG, plus a real-size preview of your icon. flatpak install flathub org.gnome.design.IconLibrary org.gnome.design.IconPreview
  • Free SVG icon sets: Phosphor (MIT), Tabler (MIT), Lucide (ISC), Material Symbols (Apache 2.0). Search for x, close, minus, plus, square, chevron, maximize.
  • Those icons are just the symbol, drawn with a stroke. To turn one into a button: put a circle behind it in Inkscape, convert the stroke to a path and export.
  • Buttons from existing themes (WhiteSur, Orchis, Colloid, Fluent…) on gnome-look.org (GTK3/4 Themes section): download the theme and look inside assets for files with titlebutton, close or window in the name. Those themes are usually GPL: fine for personal use.
  • SVGOMG cleans up a heavy SVG in the browser. Before using one, open it in the browser: if it shows up there, GTK can draw it too.

Making the system recognize them as icons

GTK asks for the buttons by icon name: window-close-symbolic, window-maximize-symbolic, window-minimize-symbolic and window-restore-symbolic. An icon theme of your own with those files replaces the buttons without touching the GTK theme, and the symbol is painted in the text color:

~/.local/share/icons/MyIcons/
├── index.theme
└── scalable/actions/
    ├── window-close-symbolic.svg
    ├── window-maximize-symbolic.svg
    ├── window-minimize-symbolic.svg
    └── window-restore-symbolic.svg
[Icon Theme]
Name=MyIcons
Inherits=ZorinBlue-Light,Adwaita,hicolor
Directories=scalable/actions

[scalable/actions]
Size=16
MinSize=8
MaxSize=512
Type=Scalable
Context=Actions
  • -symbolic icons: 16×16, a single color (any color; GTK repaints it), fill only.
  • In Inherits, put the icon theme you use today: gsettings get org.gnome.desktop.interface icon-theme.
  • Activate it with gsettings set org.gnome.desktop.interface icon-theme MyIcons and reopen your apps.
  • This route only shows up with the Zorin button style. With Circles and Plain, or with a custom icon, the theme draws the button and hides the system icon.

Limit of both routes: apps that draw their own title bar (Chrome, VS Code and other Electron apps, Qt apps) don't use the GTK theme.
