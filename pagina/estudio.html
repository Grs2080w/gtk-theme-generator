O que cada variável mexe

Cada cor do tema original pertence a uma família. Quando você muda a cor-base da família, todas as cores dela andam juntas: mesmo deslocamento de tom, saturação proporcional e luminosidade remapeada. Por isso uma escolha só recalcula dezenas de tons.

Ícones dos botões: onde conseguir e como fazer

Fechar, maximizar e minimizar podem usar qualquer SVG ou PNG seu. O tema copia o arquivo para dentro dele e o desenha no lugar do botão, nos apps GTK3 e GTK4 (Arquivos, Configurações, Texto, Terminal…).

O formato que funciona

  • SVG quadrado, de preferência viewBox="0 0 16 16". Ele é esticado até o tamanho escolhido no controle (16 a 26 px). PNG também serve: use 64×64 ou maior, com fundo transparente.
  • O arquivo é o botão inteiro: desenhe o círculo (ou o formato que quiser) e o símbolo juntos, e deixe 1 px de folga nas bordas.
  • As cores ficam fixas no arquivo. Não mudam com o destaque nem quando a janela perde o foco; nesse caso o tema só deixa o botão mais apagado.
  • Nada de texto, fonte ou imagem embutida. No Inkscape: selecione tudo, use Caminho → Objeto para caminho (Object to Path) e Caminho → Contorno para caminho (Stroke to Path), e salve como SVG otimizado.
  • Nome sem espaços: icones/fechar.svg. O palette.conf lê só a primeira palavra depois do =.
  • Opcional: um ícone de restaurar, que aparece no lugar do maximizar quando a janela está maximizada. Sem ele, o de maximizar é usado.

Modelos prontos: own-theme/icones/exemplo-*.svg (losangos coloridos). Abra um no Inkscape e use como ponto de partida.

Onde conseguir

  • Icon Library e Icon Preview (apps do GNOME no Flathub): todos os símbolos do GNOME para copiar em SVG, e uma prévia do ícone em tamanho real. flatpak install flathub org.gnome.design.IconLibrary org.gnome.design.IconPreview
  • Conjuntos livres de ícones em SVG: Phosphor (MIT), Tabler (MIT), Lucide (ISC), Material Symbols (Apache 2.0). Procure por x, close, minus, plus, square, chevron, maximize.
  • Esses ícones são só o símbolo, desenhado com traço. Para virar botão: coloque um círculo atrás no Inkscape, transforme o traço em caminho e exporte.
  • Botões de temas prontos (WhiteSur, Orchis, Colloid, Fluent…) no gnome-look.org (seção GTK3/4 Themes): baixe o tema e procure, dentro de assets, arquivos com titlebutton, close ou window no nome. Esses temas costumam ser GPL: tudo bem para uso pessoal.
  • SVGOMG limpa um SVG pesado no navegador. Antes de usar, abra o arquivo no navegador: se aparecer lá, o GTK também desenha.

Para o sistema reconhecer como ícone

O GTK pede os botões pelo nome do ícone: window-close-symbolic, window-maximize-symbolic, window-minimize-symbolic e window-restore-symbolic. Um tema de ícones seu que tenha esses arquivos troca os botões sem mexer no tema GTK, e o símbolo é pintado na cor do texto:

~/.local/share/icons/MeusIcones/
├── index.theme
└── scalable/actions/
    ├── window-close-symbolic.svg
    ├── window-maximize-symbolic.svg
    ├── window-minimize-symbolic.svg
    └── window-restore-symbolic.svg
[Icon Theme]
Name=MeusIcones
Inherits=ZorinBlue-Light,Adwaita,hicolor
Directories=scalable/actions

[scalable/actions]
Size=16
MinSize=8
MaxSize=512
Type=Scalable
Context=Actions
  • Ícones -symbolic: 16×16, uma cor só (qualquer cor; o GTK repinta), só preenchimento.
  • No Inherits, coloque o tema de ícones que você usa hoje: gsettings get org.gnome.desktop.interface icon-theme (hoje é ZorinBlue-Light).
  • Ative com gsettings set org.gnome.desktop.interface icon-theme MeusIcones e reabra os apps.
  • Esse caminho só aparece no estilo Zorin dos botões. Nos estilos Círculos e Simples, ou com ícone próprio, o tema desenha o botão e esconde o ícone do sistema.

Limite dos dois caminhos: apps que desenham a própria barra de título (Chrome/VS Code e outros Electron, apps Qt) não usam o tema GTK.

Aplicar no Zorin

      
    
        
  1. Cole o conteúdo em own-theme/palette.conf.
    2. 
        
  2. Dentro da pasta own-theme, rode ./instalar.sh --aplicar. Ele gera o tema, move para /usr/share/themes (pede sua senha) e ativa.
    3. 
        
  3. Se escolheu ícones próprios, copie os arquivos para own-theme/icones/ antes, com o nome que aparece no palette.conf.
    4. 
        
  4. O painel muda na hora. Feche e reabra os apps para ver o resto. Com o blur marcado, o instalar.sh também liga o blur dos apps no Blur my Shell. Para desligar depois, abra as preferências da extensão: Aplicativos → Borrar.
    5. 
        
  5. Para voltar ao original: gsettings set org.gnome.desktop.interface gtk-theme ZorinBlue-Light e gsettings set org.gnome.shell.extensions.user-theme name ZorinBlue-Light.
